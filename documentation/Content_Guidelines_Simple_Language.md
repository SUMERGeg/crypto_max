# Правила простого языка для уроков

## Цель

Урок должен быть понятен пользователю без предварительного знания криптовалют и финансов. Простота означает ясный порядок объяснения, а не упрощение смысла.

## Структура урока

1. Знакомая жизненная идея.
2. Одно новое понятие и его расшифровка простыми словами.
3. Объяснение «По шагам».
4. Бытовой или числовой пример.
5. Короткий блок «Главное запомнить».
6. Мини-тест только по словам и идеям, которые уже появились в уроке.

## Правила терминов

- Не больше 1–2 новых терминов в одном коротком уроке.
- Термин нельзя использовать в вопросе или варианте ответа раньше его объяснения.
- При первом появлении используется форма: `термин — простое объяснение`.
- Если русская замена не теряет смысл, используется она: «согласие сети» перед «консенсусом», «распределение средств» перед «диверсификацией».
- Английское название даётся после понятной русской идеи, а не вместо объяснения.
- Термины из будущих уроков не используются как готовое знание.

## Редакторская проверка

Перед публикацией автор отвечает «да» на вопросы:

- Можно ли понять первый абзац без словаря?
- Объяснено ли каждое новое слово до теста?
- Есть ли конкретный пример?
- Можно ли пересказать главную мысль одним предложением?
- Не звучит ли текст как инвестиционная рекомендация?
- Нет ли обещаний доходности или отсутствия риска?

## Целевой объём

Для урока на 4–5 минут:

- 4 смысловых блока;
- 650–1 000 знаков основного текста;
- 3–5 коротких вопросов;
- один вопрос проверяет одну идею.

# Test Checklist — Crypto Education MVP

## 1. MAX / вход
- [ ] Mini-app открывается из MAX.
- [ ] Валидный MAX пользователь автоматически получает профиль.
- [ ] При повторном входе используется тот же профиль.
- [ ] Отдельная форма регистрации отсутствует.
- [ ] Невалидные launch-data отклоняются backend.

## 2. Главная
- [ ] Главная открывается после входа.
- [ ] Быстрые ссылки ведут в правильные разделы.
- [ ] «Продолжить обучение» открывает последний урок.
- [ ] Общий progress соответствует данным.
- [ ] Сбой live market-data не ломает Главную.

## 3. Учиться
- [ ] Видны 4 направления.
- [ ] Все направления доступны сразу.
- [ ] Открывается список уроков.
- [ ] Статус урока корректен.
- [ ] Открывается контент урока.
- [ ] Можно выйти без теста.
- [ ] lastOpenedLesson сохраняется.

## 4. Мини-тест
- [ ] Тест содержит 3–5 вопросов.
- [ ] Нельзя завершить тест, не ответив на обязательные вопросы.
- [ ] Correct answers не раскрываются заранее.
- [ ] Score рассчитывается корректно.
- [ ] Result сохраняется.
- [ ] Lesson становится COMPLETED.
- [ ] Progress направления пересчитывается.
- [ ] Повторная попытка создаёт новый результат.
- [ ] Более низкий повторный score не уменьшает progress.
- [ ] В профиле показывается лучший score.

## 5. Market Replay — старт
- [x] Отображается список сценариев.
- [x] Карточка не содержит спойлеров будущего.
- [x] Видна маркировка «виртуальные деньги».
- [x] Создаётся SimulationSession.
- [x] Cash равен starting balance.
- [x] Начальный portfolio пуст.

## 6. Market Replay — время
- [x] Historical date движется с нужной скоростью.
- [x] Pause останавливает время.
- [x] Resume продолжает время.
- [x] Future graph не отображается.
- [x] Future prices не приходят в API.
- [x] Future events не приходят в API.
- [x] Event появляется не раньше eventAt.
- [x] Graph обновляется по мере replay.

## 7. BUY
- [x] Можно выбрать разрешённый сценарием актив.
- [x] Можно ввести положительную сумму.
- [x] Quantity рассчитывается по historical price.
- [x] BUY <= cash проходит.
- [x] Cash уменьшается корректно.
- [x] Position увеличивается.
- [x] Transaction сохраняется.
- [ ] BUY > cash отклоняется.
- [ ] Нулевая/отрицательная сумма отклоняется.

## 8. SELL
- [ ] Можно выбрать актив из portfolio.
- [ ] SELL доступного количества проходит.
- [ ] Position уменьшается.
- [ ] Cash увеличивается.
- [ ] Transaction сохраняется.
- [ ] SELL больше position отклоняется.
- [ ] Нулевое/отрицательное количество отклоняется.

## 9. Завершение Replay
- [ ] На endDate сценарий завершается.
- [ ] Final portfolio value корректен.
- [ ] Return % корректен.
- [ ] Benchmark корректен.
- [ ] Delta к benchmark корректна.
- [ ] История решений отображается.
- [ ] Analysis rules срабатывают ожидаемо.
- [ ] Нет формулировок «правильно было купить».
- [ ] Completed session появляется в Profile.

## 10. Безопасность
- [ ] Открывается список кейсов.
- [ ] Кейс содержит 2–4 действия.
- [ ] После выбора показывается feedback.
- [ ] Показываются red flags.
- [ ] Показывается takeaway.
- [ ] Кейс становится завершённым.
- [ ] Повторное прохождение работает.
- [ ] Не запрашиваются реальные секретные данные.

## 11. Крипторынок
- [ ] Загружается список настроенных активов.
- [ ] Цена/изменение отображаются.
- [ ] Открывается detail screen.
- [ ] Graph отображается.
- [ ] Нет real BUY/SELL CTA.
- [ ] При сбое provider используется stale cache.
- [ ] Stale state обозначен.
- [ ] Без cache показывается controlled error.

## 12. Новости
- [ ] Список открывается.
- [ ] News содержит дату.
- [ ] News содержит source.
- [ ] Есть «Что произошло».
- [ ] Есть «Почему важно».
- [ ] Есть takeaway.
- [ ] Есть disclaimer.
- [ ] DRAFT не видны пользователю.

## 13. Профиль
- [ ] Overall progress корректен.
- [ ] Course progress корректен.
- [ ] Completed lessons учтены.
- [ ] Best quiz results корректны.
- [ ] Completed replay видны.
- [ ] Security case count корректен при P1.
- [ ] Переход к last lesson работает.

## 14. Privacy / Security
- [ ] Frontend bundle не содержит secret external API.
- [ ] Backend проверяет ownership SimulationSession.
- [ ] Нельзя изменить чужую session по ID.
- [ ] Нельзя клиентом подменить quiz score.
- [ ] Нельзя клиентом подменить cash balance.
- [ ] Логи не содержат sensitive secrets.
- [ ] HTTPS включён на staging/demo.

## 15. Mobile / UI
- [ ] Основной flow проверен на mobile width.
- [ ] Нет horizontal scroll на основных экранах.
- [ ] CTA доступны для нажатия.
- [ ] Graph не выходит за viewport.
- [ ] Loading/error/empty states не ломают layout.
- [ ] Робот не перекрывает основные CTA.

## 16. Smoke Test перед защитой
- [ ] Открыть mini-app из MAX.
- [ ] Открыть урок.
- [ ] Пройти тест.
- [ ] Проверить progress.
- [ ] Запустить demo Market Replay.
- [ ] Дождаться event.
- [ ] Купить актив.
- [ ] Продать актив.
- [ ] Завершить scenario.
- [ ] Проверить benchmark/analysis.
- [ ] Пройти security case.
- [ ] Открыть market.
- [ ] Открыть news.
- [ ] Открыть profile.
- [ ] Проверить сохранение ключевых результатов.

# Плоские иллюстрации для уроков о криптовалюте

Черновой набор для визуальной проверки. Изображения пока **не подключены к приложению**: после согласования их можно выборочно вставить в нужные страницы уроков.

## Общие правила набора

- одна иллюстрация объясняет одну основную мысль страницы;
- плоский светлый стиль, крупные иконки и минимум декоративных деталей;
- без мелких подписей внутри изображения: текстовое объяснение остаётся частью урока;
- синий и фиолетовый показывают нейтральный процесс, зелёный — нормальное завершение, коралловый — риск или остановку;
- робот используется как проводник, но не перекрывает саму схему.

## Что проверять

1. Понятна ли главная мысль без чтения подписи.
2. Нет ли у схемы неверного или слишком уверенного обещания.
3. Не перегружена ли она деталями.
4. Нужен ли робот именно на этой странице.
5. Подходит ли изображение по стилю к уже принятой схеме перевода через банк и Bitcoin.

# Feature Vision — Крипторынок

## 1. Назначение фичи

Раздел **«Крипторынок»** даёт пользователю простой образовательный обзор текущего состояния крипторынка: цены выбранных активов, динамику стоимости, графики и вручную подготовленные новости с короткими разборами.

Фича предназначена для понимания рыночного контекста, а не для совершения реальных сделок.

---

## 2. Пользовательская ценность

Пользователь может:

- увидеть текущую стоимость основных криптоактивов;
- понять, как меняется цена во времени;
- сравнить котировки из нескольких поддерживаемых источников;
- прочитать важные новости без информационного шума;
- получить короткое объяснение, почему событие важно;
- связать новости рынка с образовательными материалами.

Ключевой принцип:

> **Не просто показать цифры и новости, а помочь пользователю понять, что они означают.**

---

## 3. Основные модули

### 3.1. Котировки

Для ограниченного списка активов отображаются:

- название;
- тикер;
- текущая цена;
- изменение за 24 часа;
- небольшой график.

В MVP список активов фиксируется командой.

### 3.2. Экран актива

Для выбранного актива отображаются:

- название и тикер;
- текущая цена;
- изменение;
- график стоимости;
- выбор периода;
- котировки из нескольких поддерживаемых источников;
- короткое пояснение о возможных различиях цен.

### 3.3. Новости

Новости отбираются и добавляются командой вручную.

Основные категории:

- рынок;
- Россия и право;
- безопасность;
- технологии.

### 3.4. Карточка новости

Каждая новость содержит:

- заголовок;
- дату;
- категорию;
- что произошло;
- почему это важно;
- короткий разбор;
- что нужно запомнить;
- источник.

---

## 4. Основной пользовательский сценарий

### Котировки

1. Пользователь открывает **«Крипторынок»**.
2. Видит список активов.
3. Выбирает актив.
4. Открывает график.
5. Меняет период.
6. Сравнивает котировки из разных источников.

### Новости

1. Пользователь открывает вкладку **«Новости»**.
2. Видит список материалов.
3. Открывает новость.
4. Читает короткий образовательный разбор.
5. При необходимости переходит к первоисточнику.

---

## 5. Источники данных

Для MVP предполагаются два типа данных:

### Рыночные данные

Получаются из внешнего API или подготовленного источника.

Используются только для отображения:

- цены;
- динамики;
- графика.

### Новости

Добавляются командой вручную.

Это позволяет:

- контролировать качество;
- проверять формулировки;
- указывать источник;
- избегать необходимости автоматического парсинга на этапе хакатона.

---

## 6. Бизнес-правила

- Раздел не предоставляет возможность реальной покупки.
- Рыночные данные используются только в информационных и образовательных целях.
- Источник котировок должен быть известен системе.
- При сравнении площадок необходимо явно указывать, что цена может отличаться.
- Каждая новость должна иметь источник.
- Каждая новость должна иметь дату публикации.
- Контент новости добавляется и проверяется командой вручную.
- На экране новости должна присутствовать пометка, что материал не является инвестиционной рекомендацией.

---

## 7. Основные состояния

### Котировки

- данные загружаются;
- данные успешно получены;
- данные временно недоступны.

### Новости

- список материалов;
- карточка новости;
- пустой список;
- ошибка загрузки.

---

## 8. Что не входит в MVP

- автоматический парсинг законодательства;
- автоматический парсинг СМИ;
- LLM-разбор новостей;
- персональные рекомендации;
- ценовые уведомления;
- торговые сигналы;
- прогнозирование цены;
- рейтинги «что купить»;
- реальная торговля;
- ввод/вывод средств.

---

## 9. Критерий готовности фичи

Фича готова к MVP, если пользователь может:

> открыть список криптоактивов → посмотреть цену и график → сравнить несколько источников → открыть новость → прочитать короткий разбор и увидеть первоисточник.

# Crypto Education

Mobile-first образовательный mini-app: короткие уроки, мини-тесты, безопасная практика и прогресс пользователя.

Раздел «Учиться» содержит 4 направления по 5 уроков. Каждый из 20 уроков разбит на 6 смысловых страниц, 2 промежуточные проверки и итоговый тест с разбором ошибок.

Сейчас доступен первый Historical Market Replay 2020–2021: 15 проверенных событий шести категорий, метки на графике, лента открывшихся новостей, скрытое будущее, сделки с виртуальным портфелем и итоговый разбор с benchmark.

## Быстрый запуск без базы

```powershell
npm install
npm run dev
```

- Frontend: http://localhost:5173
- API: http://localhost:4100/api/v1/health

Без `DATABASE_URL` API использует память. Это удобно для просмотра, но прогресс сбрасывается после перезапуска backend.

## Запуск как мини-приложения MAX

1. Создай бота в панели MAX и получи **токен именно бота**. Не подставляй вместо него токен команды хакатона со скриншота: его назначение нужно уточнить отдельно.
2. Размести приложение как Node.js Web Service с PostgreSQL и HTTPS. Для Render: сборка `npm ci && npm run build`, запуск `npm run start`; переменные окружения `NODE_ENV=production`, `DATABASE_URL` и `MAX_BOT_TOKEN`. В репозиторий токены не добавлять.
3. Укажи публичный адрес сервиса вида `https://<service>.onrender.com` в настройках мини-приложения бота. Проверь `/api/v1/health` и открытие через кнопку бота.

При заданном `MAX_BOT_TOKEN` API проверяет подписанные данные запуска MAX и требует выданную сессию для пользовательских запросов. Вне MAX показывает экран с просьбой открыть приложение через бота. Без токена остаётся локальный демо-режим. Для сохранения прогресса в production при MAX-входе `DATABASE_URL` обязателен. Данные карьерного теста также сохраняются в PostgreSQL.

Открой `http://localhost:5173`, затем выбери **Практика → Глобальный шок и восстановление**. Один проход занимает 6 минут активного исторического времени: примерно один исторический день в секунду. Пауза останавливает время.

## Запуск с PostgreSQL

1. Запусти Docker Desktop.
2. Подними базу:

```powershell
docker compose up -d db
```

3. Скопируй `.env.example` в `.env` или задай переменные в текущем терминале:

```powershell
$env:DATABASE_URL = "postgresql://crypto:crypto_dev_only@127.0.0.1:5433/crypto_education"
npm run dev
```

При подключении API автоматически применяет миграции `0001_learning_progress.sql` и `0002_simulation_sessions.sql`. Сессии Market Replay и сделки восстанавливаются после перезапуска; активная сессия открывается на паузе, чтобы время не прошло без пользователя.

Локальный пароль из `compose.yaml` предназначен только для разработки.
